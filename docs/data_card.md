# Data Card: Credit Card Fraud Detection (OpenML ID 1597)

## Источник
- Ссылка: https://www.openml.org/search?type=data&id=1597 (зеркало оригинального датасета ULB Machine Learning Group).
- Команда загрузки: `uv run python -m mlproject.download`. Исходные данные складываются в `data/raw/` (добавлен в .gitignore).

## Лицензия
- Лицензия: Open Database License (ODbL) / Public Domain. Разрешено учебное и исследовательское применение с указанием авторства исследовательской группы ULB.

## Состав данных
- Объем: 284 807 транзакций за 2 дня сентября 2013 года.
- Колонки: 31 штука (`Time`, `V1`–`V28`, `Amount`, целевая `Class`).
- Дисбаланс: 492 мошеннические транзакции (0.172%).

## Персональные данные
Датасет полностью анонимизирован. Исходные атрибуты банковских карт и реквизиты преобразованы методом главных компонент (PCA). Признаки `Time` и `Amount` не содержат персональных идентификаторов (ФИО, телефоны и номера счетов отсутствуют). Требования 152-ФЗ соблюдены.

## Очистка и разбиение
Пропущенные значения отсутствуют (0% NaN). Для валидации выбрана стратегия разбиения по времени (`time-split`), отражающая реальный поток транзакций: первые 70% во времени — train, следующие 15% — val, финальные 15% — test. Это предотвращает утечки данных из будущего.

## Известные проблемы
Экстремальный дисбаланс классов (1:578). Большинство транзакций имеют малые суммы (медиана около 22$), однако мошеннические транзакции распределены неравномерно по суммам и часто концентрируются во временных всплесках.
