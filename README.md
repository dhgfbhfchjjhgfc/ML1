## Как запустить

```bash
uv sync                                   # зависимости (Python 3.14 uv поставит сам)
uv sync --group torch --group notebooks   # PyTorch (CPU) и marimo — для этапов 2–3
uv run python -m mlproject.data           # этап 2: очистка и разбиение
uv run python -m mlproject.train          # этап 3: модели, Optuna, MLflow
uv run python -m mlproject.evaluate       # этап 4: интервалы, калибровка, SHAP, ошибки
uv run uvicorn mlproject.api:app --port 8000   # этап 5: сервис
uv run python -m mlproject.monitor        # этап 6: отчёт о дрейфе
uv run pytest                             # все тесты
uv run python -m grader all               # автопроверка
```

## Этап 1. Постановка задачи

Сформулирована бизнес-задача антифрод-системы для карточных платежей. Выбран датасет транзакций европейских держателей карт с сильным дисбалансом классов (мошеннических операций всего 0.17%). Обоснован отказ от метрики ROC-AUC в пользу PR-AUC (Precision-Recall Area Under Curve), так как в условиях сильного дисбаланса ROC-AUC дает обманчиво оптимистичный результат. Установлен жесткий порог успеха PR-AUC >= 0.80.

## Этап 2. Данные и EDA
Проведен разведочный анализ данных Credit Card Fraud (284 807 записей, 30 числовых предикторов).
- **Наблюдение 1:** Доля мошенничества составляет всего 0.172%, что требует метрик, устойчивых к дисбалансу.
- **Наблюдение 2:** Суммы транзакций варьируются от 0 до 25 691$, медиана равна 22.0$.
- **Наблюдение 3:** Признаки V1–V28 центрированы в нуле в силу свойств PCA.
- **Наблюдение 4:** Пропущенные значения отсутствуют во всем датасете.
- **Наблюдение 5:** Применен time-split (70% train, 15% val, 15% test) по колонке Time. Сохранены графики reports/figures/eda_*.png.
